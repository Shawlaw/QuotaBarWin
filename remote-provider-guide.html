Remote Provider Guide

中文

Manifest format

Remote providers are installed from a registry and a provider.json manifest.

{
  "schemaVersion": 1,
  "id": "kimi-coding",
  "displayName": "Kimi Coding Usage",
  "runtime": "node",
  "entry": "provider.cjs",
  "requiredEnvVars": ["KIMI_API_KEY"],
  "output": "provider-snapshot-v1",
  "checksums": { "source": "sha256:<hex>" }
}

For the complete English guide, see docs/remote-provider-guide.en.md.
