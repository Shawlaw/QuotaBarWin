## [1.9.0] - 2026-11-10

### Added

- 提供方列表新增常驻「配置」入口：已就绪的提供方也能随时进入配置页查看凭据状态、替换或清除凭据，不再只在待配置/未验证时出现该按钮。
- 凭据行新增「复制」与「查看」：复制不进入 Windows 剪贴板历史与云剪贴板同步；点击查看即可显示明文，并可手动隐藏。
- 一键「转为托管」：把写在配置文件里的明文凭据迁移到应用托管存储（加密模式跟随密钥安全设置），迁移后配置文件中不再出现明文，提供方保持原状态、无需重新验证。

### Changed

- 仅修改账号名称保存不再把提供方置为未验证并停用；只有真正改变凭据绑定或运行参数时才需要重新测试。
- 高级面板删除或修改凭据绑定后，提供方同样会被置为未验证并停用，与配置页行为一致。
- 高级面板的环境变量编辑器默认隐藏应用托管绑定，新增「显示托管绑定」开关；未声明类型的变量在配置页以只读名称展示。

### Fixed

- 修复并发场景下的配置丢失：检查更新、凭据测试进行中保存设置，或保存与其他后台写入交错时，不再用旧快照覆盖对方的修改，明文凭据也不会被写回。
- 修复点击凭据字段的标题或提示文本会误触发「清除」的问题；现在点击字段标题会聚焦对应输入框，「清除」按钮在屏幕阅读器下也只播报为「清除」。

### Security

- 配置文件写入改为原子替换，写入失败不再可能留下截断的半份配置。
- 查看与复制凭据会记录不含明文的审计日志。
